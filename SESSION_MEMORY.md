## Core Architectural & User Preferences (Binding)
1. **Authentication**: Web & Android Google Sign-In use **Google Firebase Authentication** (project `loantrack-74cf6`) backed by NextAuth `'firebase'` provider (`lib/auth.ts`) and Firebase ID token verification (`lib/firebase/server.ts`, `lib/firebase/browser.ts`, `app/api/auth/firebase-precheck/route.ts`). Do **not** switch login back to Supabase OAuth PKCE.
2. **Chit Funds UX Standards**:
   - **No "AI default" UI**: Never use thick left-side border crescent stripes (`border-left: 3/4/5px solid ...`), raw stacked white cards, developer JSON editors exposed directly, or tooltips clipped inside `overflow: hidden` / `overflow-x: auto` containers. Always use `createPortal(..., document.body)` with `position: fixed` (`components/chits/FieldHelpIcon.tsx`).
   - **Theme Fidelity**: Always use project CSS custom properties (`--primary`, `--primary-dark`, `--primary-light`, `--primary-border`, `--surface`, `--bg`, `--text`, `--text-secondary`, `--border`, etc.) and reuse `*-hero`, `*-card`, `*-detail-card` patterns.
   - **Non-Technical Clarity & Full 6-Language Localization**: Never render raw internal enums (`UNORGANIZED_INFORMAL`, `AUCTION_STANDARD`, `PERCENTAGE_COMMISSION`, `ALL_MEMBERS`, `EARLIEST_BID`) as primary UI copy. Explain every rule in plain language across all 6 languages (`en`, `ta`, `hi`, `te`, `kn`, `ml`) using `dict.chits`, `lib/chits/chitConfigExplainI18n.ts`, and `lib/chits/formTooltipsI18n.ts` while keeping `npm run i18n:check` passing (`STABLE-5`).
3. **Chit Group Detail Page Rules**:
   - Only **one** main member table should be shown cleanly: if all enrolled seats (`>= totalMembers`) have `agreementStatus === 'verified'`, hide the separate enrollment `Members` table; otherwise make it **collapsible / expandable** (collapsed by default once the primary dividend breakdown table has rows).
4. **Statutory Registers & Agreement Dates**:
   - Marking an agreement `signed` or `verified` (`app/(dashboard)/[module]/chits/actions.ts` -> `updateChitMemberDetails`) automatically stamps `agreementSignedAt` if missing; Statutory Register `prior-sanction-agreement` falls back to AuditLog verification timestamp or `joinedAt` so verified rows never print `"Pending"`.
   - `bylawNo`, `priorSanctionNumber`, `registrationNo`, `registrarOffice`, and `commencementCertificate` are editable in `[id]/edit/ChitGroupEditForm.tsx` and shown in Statutory PDFs (`lib/chits/statutory/builder.ts`, `pdf.tsx`).
   - Statutory PDF tables size columns via per-column `weight` with `paddingHorizontal: 5` wrappers so `Ticket Value` (right-aligned) and `Joining Date` (left-aligned) never collide.
