Security Audit

🔴 Critical

🚨
NPA Upgrade Route — No Authentication Guard
app/api/npa/upgrade/route.ts — line ~45

Route accepts POST requests and classifies loans as NPA without calling requireApiContext() or any auth check. Any unauthenticated caller can degrade a loan's NPA status.

Fix: Add at top of handler:
const ctx = await requireApiContext(req); if (ctx.response) return ctx.response;
🚨
Old /api/npa/* Routes Not Removed — Shadow Vulnerability
app/api/npa/loans/, app/api/npa/summary/, app/api/npa/history/, app/api/npa/upgrade/

New v1 routes exist at /api/v1/npa/* (properly auth-guarded). Old routes shadow them and may have weaker auth. Old routes should be deleted entirely.
