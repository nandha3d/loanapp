GPS Enhancements for Enterprise

2.1 Web Live Map (closes G1)

Add app/(dashboard)/[module]/route-tracker/LiveMapClient.tsx using Leaflet + OpenStreetMap (free, no API key, works on the existing VPS). Poll /api/v1/gps/live every 30 s. Markers: green = online (<5 min), grey = last-known. Click marker → agent card with today's collections + "view route" link. Reuse the existing table below the map as the accessible fallback.

2.2 Mock-Location Detection (closes G2)

  • Mobile: include isMocked: p.isMocked in every ping and in the collection GPS payload.
  • Schema: AgentLocationPing.isMocked Boolean @default(false); new LocationStatus value mock_location.
  • Server: if isMocked on a collection → set location_status = 'mock_location', raise it in the route-tracker alerts column, and notify the branch admin via the existing notification pipeline.
  • Hardening (phase 2): Play Integrity API check at login for rooted/emulator devices.

2.3 Durable Ping Queue (closes G3)

Mirror the collection offline queue: persist the ping buffer to a Hive box (gps_ping_queue), flush on connectivity-restore using the existing connectivity_plus listener, cap at 1,000 entries FIFO.

2.4 Retention Cron (closes G4)

New cron GET /api/cron/gps-purge (CRON_SECRET + CronLock, same pattern as nach-present): delete agent_location_pings older than gps_retention_days (AppSetting, default 90). Keep collection geo-stamps forever — they are audit evidence; only raw movement pings expire.

2.5 Config & Privacy (closes G5, G6)

AppSetting keyDefaultEffect
gps_verify_threshold_m500Verified vs mismatch cut-off in verifyGpsAgainstGeocode
gps_retention_days90Purge-cron horizon
gps_duty_start / gps_duty_end08:00 / 20:00Pinger refuses to start outside the window; pings outside are stamped is_on_duty=false and excluded from manager views
gps_ping_interval_s30Mobile flush interval — lets tenants trade battery vs granularity

2.6 Route Replay + Field Analytics (closes G7, new value)

  • Route replay: web page that draws an agent's day as a polyline with timestamped collection pins (data already served by /api/v1/gps/history/[id]).
  • Distance-travelled report: daily km per agent (sum of haversine between consecutive pings) — feeds fuel-allowance reconciliation, a real pain point for NBFC ops.
  • Idle alerts: flag agents stationary >45 min during duty hours with pending route stops.
  • Geofenced branch check-in: auto attendance when first ping of the day is within X m of the branch.

Making It Usable by Every Grade of User

Three personas drive the design targets: field agent (may be low-literacy, gloves, sunlight, 2G), branch manager / owner (numbers-first, often older), back-office accountant (desktop web).

6.1 First-run onboarding (closes U1)

  • Role-aware 4-screen intro after first login (agent sees: scan QR → collect → sync; admin sees: dashboard → approve → track).
  • Coach-mark overlay on the collection screen the first 3 times (package: showcaseview — pure Dart, no native config).
  • "Practice mode" toggle for trainers: a sandbox customer + loan seeded per tenant so new agents can rehearse a collection without touching real books.

6.2 True voice guidance (closes U2)

  • Add flutter_tts; swap the body of VoiceAssistController.speak() — the call sites already exist, so this is a one-file change plus pubspec.
  • Speak: collection amount confirmation ("Collected ₹500 from Lakshmi — saved"), sync results, and validation errors, in the user's selected app language.
  • Numeric keypad with oversized keys on the quick-collect sheet (already a bottom sheet — increase touch targets to 56 dp).

6.3 Language completeness (closes U3)

  • Add a CI script that diffs key sets across the 6 language maps in app_strings.dart and fails on missing keys.
  • Native-speaker review pass for Tamil and Hindi first (your active market), then te/kn/ml.

6.4 Simplicity controls (closes U4, U6)

  • Simple mode (per-user toggle): agents get only Home / Collect / Customers / Sync — everything else hidden. One switch in Settings, persisted in Hive like the language choice.
  • Group the More grid into labelled sections: Daily Work · Money · Admin · Settings.
  • Text-size setting (0.9× / 1.0× / 1.15× / 1.3×) applied via MediaQuery.textScaler at app root; audit the 5 main screens at 1.3× for overflow.
  • High-contrast theme variant for sunlight readability (field agents work outdoors).

6.5 In-app help (closes U5)

  • "?" icon on the 5 core screens → bottom sheet with 3–5 illustrated steps (static assets, works offline).
  • Contact-support action: prefilled WhatsApp / phone deep-link using tenant's support_phone AppSetting.
  • Status-glossary sheet: what verified / mismatch / pending / bounced mean, in the selected language.

6.6 Telemetry (closes U7)

  • Add Sentry (Flutter + Next.js SDKs, self-hostable later): crashes, ANRs, slow API spans, with tenant + role tags (never PII).
  • Track 4 funnel events only: login success, collection submitted, sync failed, screen-load > 3s. Enough to find field pain without building an analytics empire.
