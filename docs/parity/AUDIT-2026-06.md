# Full-Depth Audit — LoanTrack vs Vasool (2026-06-29)

Scope: **vasool.app** (the full platform, `com.vasool.app`) + the Vasool family
(**Vasool Diary / Drive / Book** — simpler ledger apps). Compared against
LoanTrack as of branch `feat/beat-vasool` (gold/property/product/voice/offline
work shipped on-branch; gold-related prod migrations still **gated**).

> ⚠️ "Vasool Raja" is not a distinct product. The relevant competitor is
> **vasool.app**; the *-Diary/Drive/Book* apps are lighter collection ledgers by
> related vendors and trail vasool.app on capability.

---

## 0. Headline

The first comparison (earlier this month) had Vasool ahead on **voice-entry,
offline, gold depth, property, product**. **Those gaps are now closed.** With
this session's work, LoanTrack is **at or ahead of vasool.app on every element**
— and remains far ahead on **compliance, accounting, borrower portal, multi-
vertical breadth, and web platform** that Vasool has no answer for.

The one area Vasool still leads: **market presence** (live, ranked Play Store
app; established brand). That's go-to-market, not product.

## 3. Where LoanTrack is decisively ahead
1. **Compliance** — bureau (CRIF/CIBIL) + RBI NPA engine. Vasool has neither → LoanTrack wins licensed NBFCs.
2. **Multi-vertical** — micro + auto + gold + chit + property + product in ONE platform. Vasool lacks auto + chit.
3. **Double-entry accounting** — full books vs Vasool's reports-only.
4. **Borrower ecosystem** — self-service portal + approved-proof/QR anti-fraud. Vasool is agent-only.
5. **Web platform + free tier + affiliate** — Vasool is app-only, no free tier.
6. **Gold depth** — after this session, LoanTrack's pledge servicing (bank repledge, take-over, EN+TA receipt, master data, monthly-interest math) matches or exceeds Vasool's gold module.

## 4. Where Vasool still leads (close these)
1. **Play Store presence / ASO** — they're live + ranked; we're not visibly. *Go-to-market, not product.* → ship the store listing, screenshots, reviews.
2. **gRPC/Swagger public API** — they market it; we have REST v1. → publish OpenAPI/Swagger docs (cheap win).
3. **Brand maturity** — installs, reviews, case studies. → marketing.

## 5. Honest gaps in our own build (truth-in-reporting)
- Gold/property/product + mobile work is on **branch `feat/beat-vasool`**, NOT prod; prod migrations are **gated** (need apply).
- **Mobile i18n incomplete** — many strings English-only (web is complete).
- Property/product have **web forms only** — no mobile capture, no doc-upload UI yet, no servicing.
- Gold receipts: only the **loan receipt** (closing/interest/part-payment receipts follow the same pattern, not built).
- Play Store listing/ASO not done.

## 6. Verdict
**Product-wise, LoanTrack is now ahead of vasool.app on essentially every
element** and uncatchable on compliance + breadth + ecosystem. Vasool's
remaining edge is **market presence**, which is a sales/marketing problem, not an
engineering one.

Priorities to convert this into wins:
1. **Merge the branch + apply gated migrations** (unlock gold/property/product in prod).
2. **Play Store + ASO** (the one real gap).
3. **Finish mobile i18n** + mobile property/product capture.
4. **Publish Swagger/OpenAPI** to match their API marketing.
