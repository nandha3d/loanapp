# 04 · Profit & Loss Statement (P&L)

> Period-based income statement. Derived from `journal_lines` aggregated by Income/Expense accounts.

---

## 1. Purpose

Show **Income − Expenses = Net Profit** for a selected period, broken down by account hierarchy, with comparison to a previous period and YTD. Drill-down to individual journal entries.

### Modes

- **Summary** (default): one line per leaf account, grouped by sub-class.
- **Detail**: includes parent rollups (4000, 5000, etc.) with collapse/expand and totals at each level.

### Comparison column

- `Prev period` (e.g., previous month or quarter) — default
- `Prev year same period`
- `Hide comparison`

### Drill-down

Clicking any number opens a side panel listing journal entries that contributed to it, with totals matching. Each row links to `/journal/[id]`.

### Filters

- **Branch** — defaults to active branch; superadmin can pick "All branches".
- **Cost centre** — optional, only visible if `accountingSettings.costCentresEnabled = true`.

### Export

- **PDF**: server-rendered via `lib/accounting/pdfs/pnl.tsx` (react-pdf). Includes header (tenant name, GSTIN, period), the statement, footer with date and "Generated by LoanTrack Premium".
- **Excel**: `.xlsx` via `xlsx` library; one sheet per period (`May 2026`, `Apr 2026`).
- **Print**: client-side `window.print()` with a `@media print` stylesheet that drops chrome (sidebar, top bar, filters).

## 4. Data fetch

```ts
const periodKey  = monthKey(period);           // '2026-05'
const compareKey = monthKey(comparePeriod);    // '2026-04'

const balances = await prisma.accountBalance.findMany({
  where: {
    tenantId,
    periodKey: { in: [periodKey, compareKey] },
    account: { classType: { in: ['income', 'expense'] }, ...(branchScope ? { branchId } : {}) },
  },
  include: { account: true },
});

const ytd = await getYtdIncomeExpense(tenantId, branchId, fiscalYearStart, period.to);

const rows = buildPnlRows({
  balances,
  periodKey,
  compareKey,
  ytd,
});
```

When `account_balances` does not yet have a row for the period (first time it's queried), fall back to **on-the-fly aggregation** from `journal_lines` and write the snapshot back.

### Income calculation (per account)

`Income amount = Σ credit − Σ debit` for that account in the period (because income accounts have `normalSide = credit`). Reversals automatically net out.

### Expense calculation (per account)

`Expense amount = Σ debit − Σ credit`.

### Net Profit

`Net Profit = Total Income − Total Expenses`. Stored nowhere except derived in the report; the **Current Year Earnings** equity account is updated only on **period close** (see 12).

### Margin

`Margin % = (Net Profit / Total Income) × 100`. Negative profit → red text.

## 5. Branch / cost centre rollup

If branch scope is "All branches", figures are summed across branches. The export PDF includes a footer note "Consolidated across all branches" when so.

Cost centres are an *optional* dimension. If enabled, the P&L has an additional dropdown to filter by cost centre. Implementation: `journal_lines` gets an optional `costCentreId` column; the client filter pivots on it. Cost centres are a tenant-defined dictionary (`cost_centres` table — out of scope for v1, stub the data model now).

## 7. Edge cases

| Case | Behaviour |
|---|---|
| Period crosses a fiscal year boundary | Allowed. Comparison "Same period last year" subtracts exactly 12 months. YTD column resets at fiscal-year start. |
| Account has zero activity in the period | Hidden in **Summary**, shown as `0` in **Detail**. |
| New account created mid-period | Appears with activity only from creation date. |
| Income account used with debit (rare correction) | Reduces income amount; if total Σdebit > Σcredit, displayed in red as `(8,000)`. |
| Reversed JE | Counts as both original and reversal — net effect on P&L is zero. |
| Branch filter set, but JE has `branchId=null` | Excluded from branch view; included in "All branches". |
| Currency is non-INR (future) | v1 forces INR; display `₹` everywhere. |
| Period selector shows future month | Allowed but all numbers are 0. |

## 9. Acceptance criteria

1. P&L reconciles to Trial Balance income/expense figures for the same period.
2. Drill-down totals match the cell totals.
3. PDF export contains tenant name, GSTIN, period, statement, and a non-removable footer "Generated by LoanTrack Premium" with timestamp.
4. Branch scope is honoured on totals, drill-down, and export.
5. Reversed entries net to zero on the statement.
6. Period closing creates a JE that transfers Net Profit to `Current Year Earnings` and zeroes income/expense accounts — see 12.
